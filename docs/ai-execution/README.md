# AI Execution Documents

本目录保存供 AI 和维护者共同使用的执行文档。文档应把较大的工作拆成可独立验证的
批次，并明确每个批次的范围、前置条件、验证命令和停止条件。

## 使用约定

- 一个主题使用一个 Markdown 文件，文件名采用小写短横线形式。
- 开始执行前，重新读取根目录和目标模块最近层级的 `AGENTS.md`。
- 非平凡实现开始前，按根 `AGENTS.md` 的要求，将当前活动批次同步到根 `PLANS.md`。
- 一轮只执行一个批次；达到停止条件后记录结果并停止。
- 执行记录必须包含修改文件、验证命令、结果和未解决风险。
- 不在本目录存放密钥、RPC 凭据、生产配置或临时运行输出。
